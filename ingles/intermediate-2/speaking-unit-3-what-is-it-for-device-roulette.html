What Is It For?

The teacher loads the class roster. One roulette selects the speaker and another selects one device image. The student first names the device, then explains what it is used for.

Teacher flow

One student, one image, two spoken steps

Project the activity. The device roulette intentionally reveals only an image: it does not give the name, function, model or an instruction. The learner must supply the language aloud.

1Load all Intermediate 2 student names, then spin the speaker roulette.
2Spin the device roulette. Show the selected image only.
3Student says its name first, then what it is used for. Finish and repeat.

Student task

Look, name it, explain it

  1. Name the appliance or device: “This is a/an ___.”
  2. Say its function: “It is used to ___.”

There is no written answer on the selected image. The teacher listens and invites a brief correction or class support only after the student responds.
