Language reminder

Distance from reality, not past time

If + past, would + base verb
If I had a free year, I would travel.
Would + base verb … if + past?
Would you travel if you had a free year?
Both word orders express the same imagined present or future situation. Only punctuation changes when the If clause comes first.
