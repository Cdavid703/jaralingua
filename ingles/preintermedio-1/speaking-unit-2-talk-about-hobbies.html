Task 1 · Discuss as a class

Task 1: Discuss the questions as a class.

1. Do you think everyone should have a hobby?

Help me start

I think everyone should / does not need to have a hobby because …

Use your own view or experience. There is no single correct personal answer.

2. Do you think that some hobbies are too expensive?

Help me start

I think … can be expensive because …

Use your own view or experience. There is no single correct personal answer.

3. What hobby would you never like to do?

Help me start

I would never like to … because …

Use your own view or experience. There is no single correct personal answer.

4. What hobbies do your family do?

Help me start

People in my family enjoy …

Use your own view or experience. There is no single correct personal answer.

5. What hobbies do your friends do?

Help me start

My friends enjoy …

Use your own view or experience. There is no single correct personal answer.
