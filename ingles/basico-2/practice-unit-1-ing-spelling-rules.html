Rule cards

Review before answering

Rule 1

Most verbs: add -ing

play → playing
watch → watching
go → going

Rule 2

Silent e: drop e

make → making
write → writing
come → coming

Rule 3

Short CVC: double the consonant

run → running
sit → sitting
swim → swimming

Rule 4

ie: change to y

lie → lying
die → dying
tie → tying

Rule 5

Final y: keep y

study → studying
try → trying
enjoy → enjoying

Rule 6

Do not double w, x, or y

snow → snowing
fix → fixing
play → playing
