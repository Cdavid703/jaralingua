Meaning first: we do not change an adjective only to practise grammar. We use a comparative when two things are different in one quality: Bogotá is colder than Medellín.

Rule review

Choose the form that the adjective needs

Rule 1

Short adjective

Add -er.

cold → colder
tall → taller
old → older

Rule 2

Ending in e

Add only -r.

large → larger
nice → nicer

Rule 3

CVC pattern

Double the final consonant + -er.

big → bigger
hot → hotter

Rule 4

Long adjective

Use more + adjective.

more beautiful
more expensive
more interesting

Rule 5

Irregular adjective

Change the word.

good → better
bad → worse
far → farther
