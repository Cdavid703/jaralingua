Privacidad

Politica de privacidad

Ultima actualizacion: 31 de mayo de 2026

Datos que puede usar el sitio

JaraLingua es un sitio educativo. Algunas paginas pueden usar inicio de sesion con Google o Microsoft para identificar al estudiante o al profesor, guardar progreso, mostrar notas o habilitar descargas.

Datos de autenticacion

Cuando una persona inicia sesion, el navegador puede guardar informacion basica de la cuenta, como nombre, correo, identificador de usuario, foto de perfil y vencimiento de sesion. Esto se usa para mostrar el estado de acceso y asociar progreso educativo.

Datos academicos

Las paginas de notas y progreso pueden mostrar registros asociados a un correo autorizado. El objetivo es que cada estudiante consulte solo su informacion y que docentes autorizados puedan revisar grupos cuando corresponda.

Servicios externos

El sitio puede cargar servicios de Google para autenticacion, Microsoft para autenticacion, y YouTube para videos educativos. Las politicas de esos proveedores aplican a sus propios servicios.

Solicitudes

Para solicitar revision, correccion o eliminacion de datos asociados a una cuenta, contacta al responsable del curso o del sitio.
