Datos y roles

Uso de datos en JaraLingua

Ultima actualizacion: 31 de mayo de 2026

Autenticacion

El login se usa para reconocer usuarios y habilitar funciones como progreso, notas y descargas protegidas. El sitio no solicita contrasenas directamente; la autenticacion ocurre con proveedores como Google o Microsoft.

Progreso

El sitio puede guardar informacion de progreso por pagina, estado de actividad y campos de practica para mejorar continuidad entre sesiones.

Notas

Las paginas de notas consultan registros autorizados y deben limitar la informacion segun el rol: estudiante, profesor o administrador.

Descargas

Algunas descargas son publicas y otras estan pensadas para profesores. Las transcripciones de profesor deben mostrarse solo a cuentas aprobadas con rol docente o administrador.

Minimizacion

JaraLingua debe recolectar solo los datos necesarios para operar el curso y evitar pedir informacion sensible que no sea necesaria para el aprendizaje.
