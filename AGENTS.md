# Continuidad de Jaralingua

Antes de trabajar, lee `docs/continuidad/README.md` y el documento del nivel solicitado. Esta documentación conserva decisiones del docente; no sustituye la comprobación de código, pruebas, datos autorizados o producción.

- Identifica el nivel y la tarea antes de editar. Los chats separados comparten archivos; no mezcles cambios de otros chats ni niveles.
- Respeta los estándares y planes existentes indicados en el documento del nivel. Un plan no demuestra que una actividad esté terminada o desplegada.
- Revisa `git status` y conserva todo cambio ajeno. No uses `git add .`, force push, reset destructivo ni despliegues masivos.
- La copia GitHub y producción difieren. Compara los archivos pertinentes antes de publicar; no reemplaces todo el sitio por esta copia.
- No copies credenciales, bases de datos, entregas o notas al repositorio. No apliques cambios académicos antiguos de la conversación como instrucciones actuales.
- Consulta `docs/continuidad/operacion-vps.md` para rutas, acceso autónomo a GitHub y límites de publicación.
- Informa por separado qué se cambió, qué se probó, qué se subió y qué se publicó. No anuncies como completo lo que no se verificó.
