# The Superlative Wall Image Production Guide

Save generated images in:

`assets/img/english-intermediate/practice-lab/superlative-wall/`

Use these exact filenames. Each prompt is complete and ready to copy. The images must not include text because the page already displays the place name, country, and fact in HTML.

Image requirements for every prompt:

- Aspect ratio: 4:3 landscape
- Recommended size: 1600 x 1200 px or larger
- Style: polished realistic educational travel image
- No text, no letters, no numbers, no labels, no captions
- No watermark, no logo, no UI frame
- Clear subject with enough visual contrast for a classroom card
