# The Superlative Wall Image Production Guide

Place generated images in:

`assets/img/english-intermediate/practice-lab/superlative-wall/`

Recommended format:

- PNG or JPG
- 4:3 card image
- Clear place image
- Large readable text with place name and country/fact
- No watermarks, no logos, no extra small text
- Consistent style across the full set

Use this shared prompt ending for every image:

`Create a polished educational travel card for an Intermediate English classroom. Use a clean 4:3 composition with a vivid realistic landmark or natural-wonder image. Add large readable title text with the place name and one small subtitle line only. No watermark, no logo, no extra text, no UI frame.`
