Tratamiento de datos

Este documento resume el tratamiento de datos para instituciones, docentes y estudiantes que usan JaraLingua.

Finalidades

Los datos se usan para autenticar usuarios, mostrar contenido educativo, habilitar funciones de profesor y mantener la seguridad del sitio.

Datos tratados

Segun el uso, pueden tratarse nombre, correo institucional, rol, progreso, respuestas de actividades y metadatos tecnicos basicos del navegador.

Retencion y eliminacion

Los datos educativos se conservan mientras sean necesarios para el curso o la relacion academica. Una institucion puede solicitar revision o eliminacion cuando corresponda.

Terceros

Google, Microsoft y YouTube pueden procesar datos segun sus propias politicas cuando el usuario inicia sesion o reproduce contenido insertado.
