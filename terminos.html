Proposito del sitio

JaraLingua ofrece materiales educativos para el aprendizaje de idiomas. El contenido se entrega para estudio, practica, acompanamiento docente y actividades de clase.

Uso permitido

Estudiantes, docentes e instituciones pueden usar las paginas para aprender, practicar, proyectar actividades en clase y descargar materiales habilitados para su rol.

Uso no permitido

No se permite intentar acceder a materiales restringidos, manipular roles, automatizar abusivamente descargas, copiar credenciales, atacar el servidor o presentar el contenido como propio sin autorizacion.

Contenido externo

Algunos enlaces llevan a recursos educativos externos. JaraLingua no controla las politicas, disponibilidad o contenido de esos sitios.

Cambios

Las actividades, politicas y funciones pueden cambiar para mejorar seguridad, claridad pedagogica o cumplimiento institucional.
