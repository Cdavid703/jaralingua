# Paquete Spotify · Français B1 · Niveau 7

Este paquete contiene únicamente los audios largos B1 de la `Bibliothèque audio` del Nivel 7 que tienen actividad de preguntas en JaraLingua.

No incluye audios de vocabulario, fonética, conectores ni palabras sueltas.

## Carpeta de audios

Coloca/sube los archivos desde:

`frances/Niveau 7/spotify-niveau7/episodes/`

## Archivos incluidos

- `metadata.csv`: tabla para revisar título, archivo, reseña, enlace de actividad y URL pública sugerida del audio.
- `descriptions-spotify.md`: textos listos para copiar en la descripción de cada episodio.
- `rss-draft.xml`: borrador técnico de RSS si más adelante se quiere intentar una importación desde feed.

## Flujo recomendado

1. En Spotify for Creators, crear un nuevo episodio.
2. Subir el MP3 correspondiente.
3. Copiar el título desde `metadata.csv`.
4. Copiar la descripción desde `descriptions-spotify.md`.
5. Publicar o dejar programado.
6. Cuando Spotify entregue el enlace del episodio, guardarlo para enlazarlo después desde JaraLingua.

## Nota sobre los enlaces

Las descripciones usan enlaces de producción con este dominio:

`https://www.jaralingua.com`

Si el despliegue del Nivel 7 cambia de ruta, se deben actualizar los enlaces antes de publicar.
