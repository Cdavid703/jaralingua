Thème 02 · Si + plus-que-parfait

Hypothèses irréelles dans le passé

Imaginer ce qui aurait pu se passer si une condition passée avait été différente.

Ce thème sert à parler d'un passé qui n'a pas existé : une décision différente, une catastrophe évitée, une occasion manquée ou une version alternative de l'histoire.

Sens communicatif

Un fait réel, une version imaginaire

L'hypothèse irréelle dans le passé compare ce qui s'est vraiment passé avec une conséquence imaginaire.

Le passé réel

Le train est parti à 8 h. Marie est arrivée à 8 h 10. Elle a raté son entretien.

Marie est arrivée trop tard.

Le passé imaginé

On change une condition passée et on imagine une autre conséquence.

Si Marie était partie plus tôt, elle n'aurait pas raté son entretien.

Structure centrale

Si + plus-que-parfait, conditionnel passé

C'est la structure principale pour formuler une hypothèse impossible à changer parce qu'elle appartient déjà au passé.

Condition passée

La partie avec si présente le fait qui aurait dû être différent.

Si + plus-que-parfait
Si j'avais vérifié...

Conséquence imaginaire

La deuxième partie présente le résultat qui n'a pas eu lieu.

conditionnel passé
j'aurais évité l'erreur.

Phrase complète

Les deux parties peuvent changer d'ordre, mais la conjugaison reste la même.

Si j'avais vérifié, j'aurais évité l'erreur.
J'aurais évité l'erreur si j'avais vérifié.

Former les temps

Deux temps composés à maîtriser

Le plus-que-parfait exprime l'action antérieure imaginaire. Le conditionnel passé exprime la conséquence non réalisée.

TempsFormationExemples
Plus-que-parfaitavoir / être à l'imparfait + participe passéj'avais étudié · elle était partie · nous avions compris
Conditionnel passéaurais / serais + participe passéj'aurais réussi · elle serait venue · nous aurions compris
Phrase complètesi + plus-que-parfait + conditionnel passéSi nous avions réservé, nous aurions eu une table.

Accords importants

  • Avec être, le participe passé s'accorde avec le sujet : elles seraient arrivées.
  • Les verbes pronominaux prennent être : je me serais préparé, elles se seraient souvenues.
  • Avec avoir, le participe ne s'accorde pas, sauf si le complément direct est placé avant : les erreurs que j'aurais évitées.

Rappel approfondi

Passé composé, COD et accords

Cette partie est un renforcement : ouvrez seulement le cas que vous voulez revoir avant de faire l'activité 02G.

La logique en 4 questions

1Quel auxiliaire ?

La majorité des verbes prennent avoir. Les verbes de mouvement fréquents et les pronominaux prennent souvent être.

2Y a-t-il un COD ?

Le COD répond à qui ? ou quoi ? après le verbe : j'ai lu quoi ? la lettre.

3Où est le COD ?

Avec avoir, on accorde seulement si le COD est avant le verbe.

4Quel accord ?

Féminin : -e. Pluriel : -s. Féminin pluriel : -es.

Avec avoir : quand le COD est après le verbe
J'ai regardé la vidéo.COD après le verbe : pas d'accord visible sur regardé.
Nous avons corrigé les erreurs.Avec avoir, le participe reste invariable quand le COD vient après.
Avec avoir : quand le COD est avant le verbe
La vidéo que j'ai regardée était utile.Que remplace la vidéo : féminin singulier, donc regardée.
Les erreurs que nous avons corrigées.Que remplace les erreurs : féminin pluriel, donc corrigées.
Je l'ai comprise.l' remplace une explication : féminin singulier, donc comprise.
Avec être : accord avec le sujet
Elle est arrivée en retard.Arriver prend être : accord avec elle.
Ils sont partis tôt. Elles sont parties tôt.Le participe change selon le genre et le nombre du sujet.
Si elles étaient arrivées plus tôt, elles auraient compris la consigne.La même logique se retrouve dans le plus-que-parfait.
Verbes de la maison d'être qui peuvent aussi prendre avoir

Aller, venir, arriver, partir, entrer, sortir, monter, descendre, naître, mourir, tomber, rester, retourner, passer prennent souvent être. Mais certains changent avec un objet direct.

Elle est sortie.Pas de COD : mouvement de la personne, donc être.
Elle a sorti ses notes.Sortir quoi ? ses notes. COD après, donc avoir.
Marie est montée.Monter sans objet direct : être.
Marie a monté les valises.Monter quoi ? les valises. COD après, donc avoir.
Verbes pronominaux : accord direct ou pas d'accord
Elle s'est préparée.se représente elle-même comme COD : accord avec elle.
Ils se sont inscrits.se représente les personnes inscrites : accord masculin pluriel.
Elle s'est lavé les mains.Le COD les mains vient après : pas d'accord avec elle.
Pourquoi ce rappel sert aux hypothèses irréelles
Si j'avais envoyé la lettre, la situation aurait changé.Plus-que-parfait : avais envoyé. COD après : pas d'accord.
Je l'aurais envoyée plus tôt.Conditionnel passé : aurais envoyée. l' remplace la lettre, COD avant.
Si elle s'était préparée, elle aurait été plus calme.Pronominal au plus-que-parfait : accord avec elle.

Erreurs fréquentes

Ce qu'il faut éviter

Pas de conditionnel après si

On ne dit pas si j'aurais su.

Incorrect : Si j'aurais su, je serais venu.Correct : Si j'avais su, je serais venu.

Ne pas oublier le participe passé

Après aurais ou serais, le verbe principal est au participe passé.

Incorrect : j'aurais partir.Correct : je serais parti.

Choisir le bon auxiliaire

Les verbes de mouvement fréquents et les pronominaux prennent être.

Incorrect : elle aurait arrivé.Correct : elle serait arrivée.
