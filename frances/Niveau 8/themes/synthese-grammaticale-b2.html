Thème 09 · Synthèse grammaticale B2

Précision syntaxique et reformulation B2

Transformer des phrases correctes en discours précis : voix passive, futur antérieur, ce dont, gérondif et participe présent.

Ce thème consolide les structures transversales du niveau 8. Elles servent à reformuler une source, synthétiser un article, présenter un projet de ville intelligente et argumenter sans perdre la nuance.

Étudier Écoute 09A Conversation 09R

Objectif communicatif

Dire moins, mais dire mieux

Au niveau B2, la correction ne suffit plus. L'étudiant doit mettre en relation des informations, préciser ce qui est important, reformuler une source et choisir une structure qui rend l'idée plus claire.

Mettre en relief

Identifier ce qui compte vraiment dans une information.

Ce dont la ville a besoin, c'est d'une donnée fiable.

Organiser le temps

Montrer qu'une action sera terminée avant une autre.

Quand les experts auront vérifié les chiffres, ils publieront leur avis.

Reformuler avec nuance

Éviter la répétition et condenser une idée sans l'appauvrir.

En comparant les sources, on peut mettre les points sur les i.

Grammaire centrale

Cinq outils pour une phrase B2

Ces structures apparaissent dans les thèmes précédents, mais ici elles deviennent un système de précision. L'idée n'est pas de les empiler, mais de les choisir selon l'effet recherché.

StructureQuand l'utiliserExemple guidé
Voix passiveQuand le résultat ou l'objet de l'action est plus important que l'auteur.Les données ont été corrigées après la réunion.
Futur antérieurQuand une action future sera terminée avant une autre action future.Dès que le groupe aura comparé les sources, il présentera une conclusion.
Ce dontPour reprendre une idée liée à un verbe ou adjectif avec de : avoir besoin de, dépendre de, se méfier de.Ce dont je me méfie, c'est d'une statistique sans contexte.
GérondifPour exprimer le moyen, la manière, la simultanéité ou parfois la cause.En reformulant l'article, l'étudiant montre qu'il l'a compris.
Participe présentPour condenser une relative quand le sujet est clair.Les étudiants souhaitant convaincre doivent citer leurs sources.

COD, accord et cohérence

Pourquoi l'accord change parfois

Dans une synthèse, les accords donnent de la crédibilité. Avec avoir, le participe passé ne s'accorde pas avec le sujet, mais il s'accorde avec le COD si ce COD est placé avant le verbe.

  • La ville a publié les données. → pas d'accord avec le sujet.
  • Les données que la ville a publiées sont contestées. → le COD que reprend les données avant le verbe.
  • Les données ont été publiées. → voix passive avec être, accord avec le sujet.
  • Les experts se sont réunis. → verbe pronominal sans COD direct après le verbe.

Expression idiomatique

Mettre les points sur les i

Cette expression signifie clarifier une situation, préciser ce qui était ambigu ou corriger une confusion. Elle convient très bien quand on reformule un rapport ou qu'on répond à une information imprécise.

Avant l'exposé, il faut mettre les points sur les i : quelle source est fiable, quelle donnée est vérifiée, et ce dont nous parlons exactement.

Compréhension écrite

Un rapport plus clair pour la ville intelligente

Dans le cadre d'un projet sur la ville intelligente, un groupe d'étudiants a analysé un court article sur les capteurs installés dans les transports publics. Au début, leur résumé était trop général : ils affirmaient que la technologie allait résoudre les problèmes de circulation. Après une deuxième lecture, ils ont compris que plusieurs données avaient été collectées sans expliquer clairement qui les utilisait. Ce dont les habitants avaient besoin, ce n'était pas seulement d'une application rapide, mais d'une information transparente.

En comparant l'article avec une note municipale, les étudiants ont mis les points sur les i : quand les données auront été vérifiées par un organisme indépendant, le débat pourra devenir plus sérieux. Les personnes souhaitant défendre ce projet devront donc parler des avantages, mais aussi des limites. Une ville connectée peut améliorer les services; toutefois, elle doit rester lisible pour les citoyens.

Questions

1. Quel était le problème du premier résumé ?

Il était trop général et présentait la technologie comme une solution automatique.

2. Que signifie “ce dont les habitants avaient besoin” ?

Les habitants avaient besoin d'une information transparente.

3. Quelle condition rendra le débat plus sérieux ?

Les données devront avoir été vérifiées par un organisme indépendant.

4. Quelle structure passive apparaît dans le texte ?

“Les données avaient été collectées” ou “les données auront été vérifiées”.

5. Quelle nuance finale est défendue ?

La ville connectée peut améliorer les services, mais elle doit rester lisible pour les citoyens.
