# Prompts profesionales para reemplazar imágenes de actividades · Français Niveau 1

Este documento reemplaza el enfoque anterior de imágenes tipo tarjeta con texto.  
Para las actividades, la imagen **no debe contener texto generado**, porque el título, la categoría y el botón ya los pone la página.

## Carpeta de destino

Guarda todas las imágenes generadas aquí:

`D:\Jaralingua\frances\Niveau 1\img\ateliers\`

Ruta web equivalente:

`/frances/Niveau%201/img/ateliers/`

Cada imagen debe conservar exactamente el nombre de archivo indicado.

## Especificaciones obligatorias para todas

- Tamaño: **1920 × 1080 px**
- Formato: **PNG**
- Perfil de color: **sRGB**
- Estilo: fotografía editorial educativa, realista, cálida, moderna, coherente con JaraLingua.
- Composición: horizontal 16:9, sujeto principal centrado o ligeramente desplazado, espacio visual limpio.
- Iluminación: natural, suave, ambiente académico o cotidiano.
- Calidad: alta, sin pixelación, sin artefactos, sin deformaciones.
- Importante: **sin texto, sin letras, sin números, sin pantallas con texto legible, sin logos, sin marcas de agua, sin UI, sin iconos flotantes**.
- Rostros y manos: naturales, anatómicamente correctos.
- Diversidad: adultos jóvenes y adultos, ambiente multicultural, estilo Francia/Latinoamérica sutil.

Prompt negativo común para pegar al final de cada prompt:

`No text, no letters, no numbers, no logo, no watermark, no UI, no captions, no posters with readable words, no distorted hands, no extra fingers, no blurry faces, no low resolution, no cartoonish flat graphic, no fake interface.`

## Recomendación de reemplazo

Cuando tengas los PNG:

1. Guarda cada archivo con el nombre exacto indicado.
2. Reemplaza el PNG existente en:

   `D:\Jaralingua\frances\Niveau 1\img\ateliers\`

3. No cambies el HTML si el nombre del archivo se conserva.
4. Después de reemplazar, conviene optimizar peso de imagen sin cambiar el nombre.

## Nota importante

Si el generador externo crea texto dentro de la imagen, rechaza esa salida y vuelve a generar.  
Las imágenes de actividades deben funcionar como **escenas visuales**, no como diapositivas ni carteles.
