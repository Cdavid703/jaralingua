Les Nombres et les Dates en Français

Savoir utiliser les nombres et dire la date est essentiel dans la vie de tous les jours : pour prendre un rendez-vous, donner son âge, ou parler d'événements historiques. Cette leçon vous guidera à travers tout ce que vous devez savoir.

Partie 1 : Les Nombres (Les Chiffres)

De 0 à 19 : La base

La première étape est de mémoriser les nombres de 0 à 19, car ils sont la base de tout le système.

  • 0: zéro
  • 1: un
  • 2: deux
  • 3: trois
  • 4: quatre
  • 5: cinq
  • 6: six
  • 7: sept
  • 8: huit
  • 9: neuf
  • 10: dix
  • 11: onze
  • 12: douze
  • 13: treize
  • 14: quatorze
  • 15: quinze
  • 16: seize
  • 17: dix-sept (10+7)
  • 18: dix-huit (10+8)
  • 19: dix-neuf (10+9)

Les dizaines : 20, 30, 40...

  • 20: vingt
  • 30: trente
  • 40: quarante
  • 50: cinquante
  • 60: soixante

Règle pour combiner : "dizaine-unité"

Pour former un nombre comme 42, on utilise un trait d'union : quarante-deux.
Exception : Pour 21, 31, 41, 51, 61, on utilise "et un". Exemple : vingt et un, trente et un.

Les particularités : 70, 80, 90

C'est ici que le français devient... intéressant !

  • 70 : soixante-dix. On continue de compter après 60. Ex: 71 = soixante-onze, 72 = soixante-douze.
  • 80 : quatre-vingts. Littéralement "quatre vingts" (4 x 20). Notez le "s" à la fin de "vingt".
    Attention : Le "s" disparaît si un autre nombre suit. Ex: quatre-vingt-un, quatre-vingt-deux.
  • 90 : quatre-vingt-dix. On continue de compter après 80. Ex: 91 = quatre-vingt-onze, 92 = quatre-vingt-douze.

Comment dire et écrire la date

Formule : le + [nombre] + [mois] + [année]

La règle la plus importante : On utilise toujours le nombre cardinal (deux, trois, quatre...), sauf pour le premier jour du mois, où on utilise l'ordinal "premier".

Exemples de dates

  • 1er janvier 2026 -> le premier janvier deux mille vingt-six
  • 2 août 2025 -> le deux août deux mille vingt-cinq
  • 14 juillet 1789 -> le quatorze juillet mille sept cent quatre-vingt-neuf
  • 21 juin -> le vingt et un juin

Demander la date

Pour demander la date, vous pouvez dire :

  • Quelle est la date aujourd'hui ?
  • Nous sommes quel jour ?

Réponse : Aujourd'hui, nous sommes le 21 août 2025. (Aujourd'hui, on est le 21 août 2025.)
