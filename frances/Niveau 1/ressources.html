Ressources du cours

Des outils gratuits ou freemium pour pratiquer le français au-delà de JaraLingua.

Cette sélection accompagne le niveau 1 : écouter, répéter, chanter, revoir le vocabulaire, vérifier une prononciation et consolider la grammaire de base avec des ressources fiables.

Explorer les ressources Coin phonétique

Sélection pédagogique

15+ sites pour progresser avec méthode

Au niveau A1, il faut privilégier les ressources visuelles, l’audio clair, les exercices autocorrectifs et les séances courtes. Certaines plateformes proposent une version premium, mais chacune offre un usage gratuit ou du contenu gratuit réellement utile.

GratuitA1

TV5MONDE · Première classe

Usage recommandé : excellent point de départ pour les salutations, les présentations, la vie quotidienne et la compréhension orale avec de courtes vidéos guidées.

Ouvrir la ressource
GratuitA1-A2

RFI Français facile

Usage recommandé : audios, exercices et transcriptions. Pour le niveau 1, choisir les contenus les plus simples et répéter de courts passages pour entraîner l’oreille.

Ouvrir la ressource
MusiquePlan gratuit

LyricsTraining / LingoClip

Usage recommandé : compléter des paroles de chansons pendant l’écoute. En A1, travailler une seule strophe, en mode débutant, avec des chansons lentes.

Ouvrir la ressource
GratuitA1

LanguageGuide · French Vocabulary

Usage recommandé : vocabulaire visuel avec audio. Très utile pour les nombres, les objets, la famille, la maison et les thèmes concrets du niveau.

Ouvrir la ressource
GratuitPrononciation

Forvo · Prononciation française

Usage recommandé : dictionnaire de prononciation avec voix natives. À utiliser pour vérifier un mot isolé avant un enregistrement ou une répétition en classe.

Ouvrir la ressource
Plan gratuitPrononciation

YouGlish French

Usage recommandé : rechercher des mots dans des vidéos authentiques. En A1, essayer des phrases simples : bonjour, je m’appelle, comment ça va.

Ouvrir la ressource
