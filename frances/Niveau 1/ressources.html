Ressources du cours

Sitios gratuitos o con plan gratis para practicar francés fuera de JaraLingua.

Esta selección conecta el nivel 1 con herramientas externas para escuchar, repetir, cantar, practicar vocabulario, verificar pronunciación y reforzar gramática básica.

Ver enlaces Coin phonétique

Curaduría externa

15+ sitios para empezar bien

Para A1 conviene priorizar recursos visuales, audio claro, ejercicios autocorregibles y práctica corta. Algunas plataformas tienen versión premium, pero todas ofrecen uso gratuito o contenido gratuito útil.

GratisA1

TV5MONDE · Première classe

Reseña: excelente punto de partida para saludos, presentaciones, vida cotidiana y comprensión oral con videos cortos. Es ideal para estudiantes que necesitan escuchar francés real pero guiado.

Abrir recurso
GratisA1-A2

RFI Français facile

Reseña: ofrece audios, ejercicios y transcripciones. Para nivel 1 conviene usar los contenidos más simples y repetir fragmentos cortos para entrenar el oído.

Abrir recurso
MúsicaPlan gratis

LyricsTraining / LingoClip

Reseña: permite completar letras de canciones mientras se escucha. Para A1 se recomienda elegir canciones lentas, modo principiante y trabajar solo una estrofa por sesión.

Abrir recurso
GratisA1

LanguageGuide · French Vocabulary

Reseña: vocabulario visual con audio. Muy útil para números, objetos, escuela, familia y temas concretos porque el estudiante escucha al pasar por cada imagen.

Abrir recurso
GratisPronunciación

Forvo · Pronunciación francesa

Reseña: diccionario de pronunciación con voces de hablantes nativos. Sirve para verificar palabras aisladas antes de grabar o repetir en clase.

Abrir recurso
Plan gratisPronunciación

YouGlish French

Reseña: busca palabras dentro de videos reales. En A1 es mejor usar frases simples como bonjour, je m’appelle o comment ça va para escuchar ritmo natural.

Abrir recurso
GratisA1-C1

Bonjour de France

Reseña: reúne ejercicios, pruebas de nivel, vocabulario, gramática y cultura. Para nivel 1 use la categoría A1 y actividades de presentación, familia y vida diaria.

Abrir recurso
GratisDirectorio

Le Point du FLE

Reseña: es un gran directorio de recursos gratuitos FLE. Funciona como “mapa” para encontrar ejercicios por tema cuando se necesita práctica extra.

Abrir recurso
GratisEjercicios

Français Facile

Reseña: sitio clásico de cursos y ejercicios autocorregibles. Útil para reforzar artículos, presente, negación y vocabulario básico con repetición.

Abrir recurso
GratisGramática

Lingolia Français

Reseña: explicaciones claras de gramática y vocabulario con ejercicios. Conviene para consultar una regla después de verla en clase.

Abrir recurso
GratisReferencia

Lawless French

Reseña: biblioteca de explicaciones por nivel CECR. Aunque está en inglés, ayuda mucho a estudiantes autónomos que quieren una explicación ordenada y ejemplos.

Abrir recurso
GratisConjugación

Conjuguemos · Le présent

Reseña: práctica interactiva de verbos. Para nivel 1 se recomienda usar presente, verbos frecuentes y sesiones cortas de 5 a 8 minutos.

Abrir recurso
GratisUniversidad

Tex’s French Grammar

Reseña: gramática gratuita de la Universidad de Texas. Es mejor usarla como consulta puntual: artículos, verbos, pronombres y frases simples.

Abrir recurso
GratisAudio

Podcast Français Facile

Reseña: audios, dictados, diálogos y ejercicios para aprendices. En A1 es útil para escuchar conversaciones muy guiadas y repetir con pausa.

Abrir recurso
GratisDiccionario

WordReference Français

Reseña: diccionario bilingüe con ejemplos y foros. Úselo para confirmar significado, género de sustantivos y expresiones frecuentes sin depender de traducciones automáticas.

Abrir recurso
GratisContexto

Reverso Context

Reseña: muestra palabras dentro de frases reales traducidas. Para principiantes sirve si se usa con cuidado: copiar una frase corta, observar el patrón y adaptarlo.

Abrir recurso
