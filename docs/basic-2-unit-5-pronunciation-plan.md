# Unit 5 — Looking Back Pronunciation Studio

Practice Lab activity 04 follows the prior pronunciation activities: six guided sections and a final recording containing all six sections verbatim. Scope: was/were, wasn't/weren't, yes/no questions and short answers, there was/there were, past actions, went back/got over, and the taught memory idioms.

Seven ElevenLabs section/final recordings and 49 individual word recordings. Words in the reading and feedback are clickable. Both full models and word models follow the selected 0.75 or 1.0 speed. English transcription endpoint only; a non-English response is rejected.

Microphone selection, input meter, silent-recording handling, repeat attempts, recognized-word highlighting, transcript and student recording playback are inherited from Unit 4. Scores estimate reading recognition and rhythm, not a phoneme-level diagnosis.

Signed-in students can send all seven stage results to /api/basic2/unit5-looking-back-pronunciation/submit. The dedicated basic2Unit5LookingBackPronunciation entry has weight 0 and is teacher follow-up only. Submission requires seven complete stages; the server calculates the average. Duplicate client IDs return the original receipt. Client requests have bounded waits and retryable errors.
