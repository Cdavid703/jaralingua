## Alcance y fuente

Cinco expresiones ya enseñadas en la explicación de Unit 4: set up, put up y get together son phrasal verbs; in full swing y have a ball son idioms. El banco identifica el tipo de cada expresión. Cinco selectores para relacionar significados y cinco huecos de texto con pistas de significado y contextos de celebración, utilizando cada expresión una vez por bloque.

Material complementario propio basado en `tools/preintermediate1_unit4_content.py`, apartado celebration-expressions. No se atribuye al PDF ESL Pals. El mismo PDF Christmas Around the World ya publicado sirve como apoyo temático, intacto, con dos botones de descarga mediante el acceso de sesión existente. No se añade otra actividad de gramática, lectura, conversación, escritura ni evaluación oficial.

Los contextos y pistas distinguen preparar un equipo para usarlo, colgar decoraciones, reunirse, estar en pleno desarrollo y disfrutar mucho. Las frases mantienen las expresiones en su forma del banco. La página aclara que get together es el verbo y a get-together es un sustantivo; el hueco verbal no acepta la forma nominal con guion. Se aceptan mayúsculas, espacios y puntuación inicial/final superficial; se conserva la puntuación interna que distingue formas léxicas.

Claves de significados: have a ball; set up; in full swing; put up; get together. Claves de contexto: set up; in full swing; get together; have a ball; put up.
