## Objective

By the end of this unit, students understand how to name countries and nationalities, describe famous places, compare cities or countries, and use basic superlatives to talk about important places around the world.

## Scope

This implementation creates the teaching page only. It does not create Unit 3 Practice Lab activities yet.

## Topic structure

1. Countries, Nationalities, and Origin
   - country vs. nationality
   - practical country/nationality set
   - Where are you from?

2. Famous Places and Travel Descriptions
   - types of places
   - travel adjectives
   - famous for...

3. Simple Comparisons
   - comparative meaning
   - -er / more / irregular comparative forms

4. Superlatives for World Places
   - comparative vs. superlative
   - -est / the most / irregular superlatives
   - spelling rules
   - one of the most...
   - in vs. of
   - superlative questions

5. Travel Opinions and Useful Expressions
   - want to / would like to
   - think / prefer / favorite
   - travel phrasal verbs and idioms

## Superlative adaptation note

The superlative section adapts the existing Intermediate English work from `ingles/intermediate/human-natural-wonders-world-records.html`, especially:

- short adjectives: `the + adjective + -est`
- long adjectives: `the most + adjective`
- irregular forms: `the best`, `the worst`, `the farthest`
- `one of the most + adjective + plural noun`
- `in` vs. `of` with superlatives
- superlative questions

For Basic English Course 2, the explanation is simplified for A2 travel contexts: countries, cities, landmarks, and basic opinions. Measurement-heavy examples and world-record production tasks are intentionally not included at this stage.
