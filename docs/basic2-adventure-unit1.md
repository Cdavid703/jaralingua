# Basic 2 — Unit 1 Adventure

Requested 18 October 2026: six substantial challenges, approximately 20–25 minutes each, preserving Basic 2 navy/red/white and account-based progress. Duration is a pedagogical estimate, not a lock or measured student median. This is formative review; it never writes course grades.

## Content

`ingles/basico-2/adventure-unit-1.html`, linked from Games and Unit 1 Practice Lab. Six challenges, four stages each:

- Grammar Lab: 34 closed questions, plus four short application texts.
- Vocabulary in Action: 27 closed questions, plus four application texts.
- Listening Adventure: four new professional recordings, 20 questions and four application texts.
- Reading Detective: four connected texts, 20 questions and four application texts.
- Speaking Mission: three professional sentence models, four recording tasks, replay and self-review; no automated pronunciation score.
- Writing & Final Mission: planning, editing, first draft and final 100–130-word message.

All 16 quiz stages include a minimum 25-word transfer task. Self-reviewed writing has no automatic language score. The content follows Unit 1: weather, simple present versus continuous, ING spelling, going-out language, six authentic weather idioms. No tense or idiom from a later unit is required. Sources: course theory `unit-1-going-out.html`, continuity and the existing Unit 1 listening/reading plans.

101 closed questions plus 16 transfer tasks and eight extended speaking/writing tasks. Completion and mastery are distinct: a completed quiz can still need revision. XP is fixed per completed stage and cannot be farmed through repeated checking. All stages remain available for revisiting.

## Account persistence

Dedicated module `server/basic2_adventure.py`; two small hooks after the existing oral route in `server/progress_api.py`. Uses existing verified API authentication, then resolves only registered Basic 2 accounts from the roster. Client-supplied student IDs are ignored. Teachers/admins have their own preview space. No roster, student credentials or grades are sent to clients.

SQLite: `/var/lib/jaralingua/basic2-adventure.sqlite3`, override `JARALINGUA_BASIC2_ADVENTURE_DB` for synthetic tests. Records keyed by server-resolved account and stage. Per-stage revision checks prevent silent concurrent-device overwrite; operation IDs make retries idempotent. Conflict UI offers copies of both versions and an explicit choice. Last 200 receipts retained per account.

Browser IndexedDB keeps per-account drafts, recordings and pending operations. Saves run after input, on reconnect, visibility changes and periodic retry. The page distinguishes device-only from acknowledged account saves. New-device continuation requires the previous device to have synced. Server failures and expired sessions preserve local drafts. Account changes clear the visible workspace. Generic auth form autosave is excluded with `data-jaralingua-managed-draft` to prevent competing writers.

Audio: private base64 audio in account-owned SQLite records, maximum 2 MB/120 seconds per stage. Native MediaRecorder plus upload fallback. Maximum request size is bounded by module validation; audio types and container headers checked. Audio duration is client metadata for formative practice, not trusted evidence of achievement for a grade. No student recordings are sent to any speech service.
