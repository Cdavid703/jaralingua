# Basic English Course 2 - Unit 2 Grammar Activity Plan

## Activity identity

- **Activity title:** This, That, These, Those
- **Course:** Basic English Course 2
- **Unit:** Unit 2 - Shopping Experiences
- **Practice Lab number:** Activity 02
- **Activity type:** Grammar Practice
- **Estimated classroom time:** 15-20 minutes
- **Student language level:** Basic / A1+

## Pedagogical objective

Students look at shopping images and choose the correct sentence according to:

- distance: near or far;
- number: singular or plural;
- demonstrative: `this`, `that`, `these`, `those`;
- verb agreement: `is` for singular and `are` for plural.

The activity is visual and closed-response. Students do not write free answers.

## Target language

| Visual condition | Target form | Example |
| --- | --- | --- |
| near + singular | this + singular noun + is | This jacket is nice. |
| far + singular | that + singular noun + is | That dress is red. |
| near + plural | these + plural noun + are | These shoes are nice. |
| far + plural | those + plural noun + are | Those boots are black. |

## Activity structure

1. Hero with a professional activity image.
2. Activity objective.
3. Compact grammar reminder with the four forms.
4. Fifteen visual questions.
5. Each question includes:
   - one professional image;
   - click-to-enlarge image modal;
   - one prompt: `Choose the best sentence.`;
   - three answer options labeled A, B, C;
   - feedback after checking.
6. Final score.
7. Reset option.
