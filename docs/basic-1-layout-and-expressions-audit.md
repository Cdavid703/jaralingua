# Basic English Course 1 — Layout and Expressions Audit

## Full-screen layout standard

Course Overview and Practice Lab use a shared application-width layout:

- desktop content may use up to `1760px` with fluid safe gutters;
- hero areas use full viewport width and their content remains inside the same safe gutter system;
- tablet and mobile retain fluid width with no horizontal overflow;
- all six Conversation Coach pages use the same `1760px` maximum width through their shared template.

## Unit 1–3 expressions audit

The teaching pages were searched for items marked or used as idioms/phrasal verbs.

- **Unit 1: All About You:** greetings, introductions, spelling, numbers, and standard polite expressions only.
- **Unit 2: In Class:** classroom instructions, object/location vocabulary, demonstratives, and standard questions only.
- **Unit 3: Favorite People:** people/family descriptions and standard questions only.

No actual idiom or phrasal verb is currently taught in these three Unit pages. For pedagogical accuracy, greetings such as `See you later`, classroom requests, and ordinary vocabulary were not copied into the idiom bank as if they were idioms.

The library already contains real idioms for later relevant units, including routines, weather, free time, and neighborhood contexts.
